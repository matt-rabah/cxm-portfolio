# Matthew Rabah CX Portfolio

Customer experience management portfolio for [mattrabah.com](https://mattrabah.com), built with Astro 7.2.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The site uses Astro 7.2 incremental static builds and disables unused session support. Content focuses on customer success consulting at Cadence Lab, customer experience leadership at Shinola, and healthtech customer success at NeuroSync.
